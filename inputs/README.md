# Curated inputs

Hand-curated files that the pipeline reads in addition to the downloaded source data.

- `ghcnh_reference_exclusions.csv`: GHCNh stations whose reported elevation or location is contradicted by station metadata (Additional file 1: S1.1, step 1).
- `ghcnh_review_exclusions.csv`: GHCNh stations excluded after visual review of their pressure series (Additional file 1: S1.1, step 6).
- `geolocator_master_release.json`: release record and file checksums of the Master GeoLocator Data Package used for bird flight heights.
