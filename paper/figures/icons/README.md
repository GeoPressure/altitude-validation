# Figure header icons

Source: [Lucide](https://lucide.dev/), downloaded 22 October 2026 from the official repository. The original SVG files and the upstream licence are retained here.

- [radio-tower.svg](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/radio-tower.svg): weather-station column.
- [balloon.svg](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/balloon.svg): sounding column.
- [cloud-sun.svg](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/cloud-sun.svg): atmospheric-conditions row.
- [move-vertical.svg](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/move-vertical.svg): altitude-effect row.

PNG derivatives use stroke colour #566476, stroke width 1.6 and a transparent background at 256 × 256 pixels. They are displayed at approximately 5.6 mm, giving more than 1,000 pixels per inch. They were rendered from the SVGs with CairoSVG; original geometry is preserved. See LICENSE-lucide for the ISC and applicable Feather-derived MIT notices.
