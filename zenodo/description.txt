Code and data accompanying “How accurate is altitude from pressure geolocators? A global assessment of three pressure-to-altitude conversions on the ground and in flight”.

The study evaluates a fixed standard atmosphere, a conversion using ERA5 surface conditions with a standard lapse rate, and an ERA5 conversion incorporating virtual temperature and a climatological lapse rate from GPT3. Ground comparisons use NOAA GHCNh weather stations; flight-height comparisons use NOAA IGRA2 radiosondes up to 5 km above the launch surface. Each primary network contains at most one station per 200 km equal-area sampling cell, using the latest qualifying 12-month period within 2022–2026. The analyses quantify absolute errors, station bias and within-station variability, compare ERA5 with ERA5-Land, and use flight heights from 203 birds of 25 species to provide ecological context. A separate fixed pilot evaluates atmospheric-query displacement using 80 soundings from 10 stations in 2024.

altitude-validation-code.zip contains R source code, derived numerical tables and figure inputs, figures, manuscript and supplement sources, rendered documents, and supporting documentation. Superseded exploratory material is identified in archive/ and is not part of the active workflow.

altitude-validation-data.zip contains frozen station-selection inputs and accepted observations, extracted sounding profiles, ERA5 and ERA5-Land inputs, station metadata, terrain-check caches, GPT3 grids, and atmospheric caches for the fixed position-sensitivity pilot. Extract the code archive, then extract the data archive inside altitude-validation/. With the dependencies installed, run Rscript run_all.R prepare analysis position figures check from that directory. Rendering is a separate optional stage: Rscript run_all.R render. Instructions and the GeoPressureR revision used by the analysis are provided in the data README.

Individual bird trajectories are available separately in the Master GeoLocator Data Package, version 2026.0, https://doi.org/10.5281/zenodo.18187093. The aggregate weights and figure-input tables needed for the present analysis are included in the code archive.
