# Curated inputs

Hand-curated files read by the pipeline in addition to the downloaded source data.

- `ghcnh_reference_exclusions.csv`: GHCNh stations whose reported elevation or location is contradicted by station metadata (Additional file 1: S1.1).
- `ghcnh_review_exclusions.csv`: GHCNh stations excluded after visual review of their pressure series (Additional file 1: S1.1).
- `position_stations.csv`, `position_soundings.csv`: fixed sample of the horizontal-position pilot (Additional file 1: S5).
- `geolocator_master_release.json`: release record and file checksums of the Master GeoLocator Data Package used for bird flight heights.
