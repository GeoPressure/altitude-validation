# Reference library and evidence tables

Reviews, search notes and manuscript plans are organised under [`docs/`](../docs/). Start with the [literature documentation index](../docs/literature/README.md) or the [GPS/barometer Markdown review](../docs/literature/gps-barometer-ecology.md).

- `references/`: reference PDFs and extracted texts, kept locally and not tracked.
- `metadata/`: DOI metadata snapshots.
- [Reference inventory](reference_inventory.csv), [PDF index and hashes](pdf_index.csv) and [reference crosswalk](reference_crosswalk.csv).
- [Biological evidence](biological_applications.csv) and [conversion evidence](conversion_evidence.csv).
- `*.bib` and `*.ris`: curated additions and Zotero exports/import records; the manuscript bibliography remains `paper/references.bib`.
- Download, PDF-update and Zotero logs record library maintenance.

The manuscript reference PDFs in `paper/pdfs/` are also kept locally only; `paper/pdf-manifest.csv` lists them. The literature-review report itself is maintained only as Markdown in `docs/literature/`.
