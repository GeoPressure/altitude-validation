# Station-curation explorations (October 2026)

Exploratory scripts used while designing the GHCNh pressure checks, reviewing high-error stations and testing alternative filtering rules. Their conclusions are recorded in `docs/methods/reviews/`; the adopted rules are implemented in `R/ghcnh_*.R` and `scripts/sampling/ground_selection.R`. The scripts read and wrote `output/drafts/`, which is not tracked, and are not part of the pipeline.
